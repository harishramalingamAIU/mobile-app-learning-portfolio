# Android Developers Learning Pathway

The prescribed learning pathway consists of four units.

## Unit 1 — Your first Android app

**Duration:** 10 hours

This unit introduces the fundamentals of Android development.

### Main topics

- Introduction to Kotlin programming
- Kotlin programming basics
- Android Studio setup
- Creating a basic Android application
- Displaying text and images
- Running applications on an emulator or physical device

### Learning focus

This unit established the foundation for Android application development. I learned the basic development workflow and how Kotlin code is connected to an Android application's user interface and execution environment.

---

## Unit 2 — Building app UI

**Duration:** 21 hours

This unit continues Kotlin fundamentals and introduces interactive user interfaces.

### Main topics

- Kotlin conditionals
- Function types
- Classes
- Lambda expressions
- Composition and recomposition
- Buttons and user interaction
- User-entered data
- State management
- Unit testing

### Learning focus

This unit introduced the relationship between user actions, application state, and UI updates. I learned how Jetpack Compose uses a declarative approach where the UI reflects the current state of the application.

---

## Unit 3 — Display lists and use Material Design

**Duration:** 15 hours

This unit focuses on displaying collections of information and designing consistent user interfaces.

### Main topics

- Kotlin data classes
- Functions and collections
- Scrollable lists
- Text and image content
- Click listeners
- App bars
- Application themes
- Material Design
- Colours, shapes, and typography

### Learning focus

This unit demonstrated how structured data can be presented using reusable UI components. It also introduced Material Design principles for creating consistent and modern interfaces.

---

## Unit 4 — Navigation and app architecture

**Duration:** 28 hours

This unit introduces architecture, navigation, state management, and adaptive user interfaces.

### Main topics

- Activities and lifecycles
- Modern Android architecture
- StateFlow
- Unidirectional Data Flow (UDF)
- ViewModel
- Navigation with Compose
- Adaptive and responsive design
- Window size classes
- Navigation drawer

### Learning focus

This unit extended the previous concepts into a more structured application architecture. I learned how state, events, UI components, navigation, and lifecycle considerations can be organised to make applications easier to maintain and adapt.


The progression helped me understand that Android development is not only about creating individual screens. # Overall Reflection

Completing the four modules provided a progressive understanding of Android application development.

The first unit established the basic Kotlin and Android development workflow. The second unit introduced interactive interfaces and demonstrated how Compose uses state and recomposition to update the UI. The third unit extended these concepts to collections and reusable lists while introducing Material Design. The fourth unit brought the previous concepts together through application architecture, ViewModel, StateFlow, Navigation, and adaptive layouts.

One of the main lessons from the pathway is that developing a functional application and developing a maintainable application are different goals. A maintainable application requires appropriate state ownership, reusable components, clear navigation, consistent design, testing, and meaningful organisation of the source code.

The learning pathway also demonstrated that implementation decisions involve trade-offs. Simple applications may require less architecture, while larger applications benefit from clearer separation of responsibilities. Similarly, a fixed layout may be easier to implement initially, while adaptive design requires additional consideration but supports different screen sizes and form factors.

Overall, these modules developed both practical Android development skills and the ability to analyse why particular implementation techniques are appropriate.
