# Module 1 — Your first Android app

## Overview

Unit 1 introduces the foundations of Android development. It contains three pathways with a stated duration of **10 hours**.

The learning outcomes are:

- Write simple Kotlin programs that display text output.
- Download and install Android Studio.
- Build an Android app with a simple UI containing text and images.
- Run the app on a device or emulator.

## Analysis

The first stage is important because Android development depends on programming fundamentals. Kotlin concepts such as variables, functions, expressions, classes, and control flow provide the foundation for later Android work.

Android Studio introduces the practical development environment. It provides source-code editing, project/build management, debugging, emulator/device integration, and tools for running applications.

The development workflow is iterative:

**Write code → Build → Run → Observe → Debug → Improve → Test again**

Creating a simple UI with text and images establishes the connection between source code and visible application output. Running the application on an emulator or physical device provides practical evidence that the implementation works beyond compilation.

## Strengths

- Establishes Kotlin and Android fundamentals.
- Introduces the Android development environment.
- Provides a complete workflow from code to running application.
- Creates a foundation for later Compose and architecture concepts.

## Limitations and Challenges

The applications at this stage are simple, so they do not yet expose the state-management and architectural problems found in larger applications. Android Studio, SDK configuration, Gradle builds, and emulators can also introduce setup challenges.

## Reflection

The main lesson from Unit 1 was understanding the complete Android development workflow. I learned that successful application development involves not only writing code but also building, running, observing, testing, and improving the application.
